# 信贷冲击稳定器设计（D4）

> 依据：`docs/CREDIT_SHOCK_DIAGNOSIS.md`。信贷冻结 → 企业工资账单无法融资 →
> 按比例欠薪 → 部分工人 0 现金 → 粮食市场出清但买不起 → 饥饿/死亡。
> 目标不是消除冲击，而是让负反馈（最后贷款人/收入支持/食品分配）先接住家庭。
>
> **状态（V0.5.1）**：人口/养老金/粮食救济已合并；`_pay_wages` 仍按比例欠薪，
> `wage_arrears`/LLR/食品券尚未实现；下一阶段 D4。

## 1. 问题链

```
银行准备金冻结 → 工资缺口贷款缩减 → 企业现金不足
→ _pay_wages 按比例欠薪 → 工人零现金
→ 食品市场有货但买不起 → 连续 3 月饥饿 → 死亡
```

关键事实（Keynesian T122）：食品需求≈成交量，未成交 0.02–0.05 吨；
饥饿 214 ≈ 零现金 207；价格 90 未暴涨。**不是粮食供给问题。**

## 2. 机制组合（建议按顺序实现）

### A. 工资欠款显性化（所有制度）

- `Enterprise.wage_arrears: float`；`Worker.wage_arrears` 可选。
- `_pay_wages` 不再静默按比例打折；未付部分记 `wage_arrears` 负债，
  下一月现金流优先支付；连续欠薪记录 warning。
- 效果：工人有法律债权，但当期仍可能零现金 → 需要 B/C。

### B. 最后贷款人/贴现窗口（Keynesian/MMT）

- `Bank.lender_of_last_resort: bool`；工资账单缺口可临时使用
  `Bank.frozen_cash`（冻结准备金只是不可放贷，不是不存在）或以政府担保放贷。
- MMT：央行直接提供准备金/购买政府债券；Keynesian：央行贴现窗口，
  政府债券/银行权益吸收损失。
- 古典：无央行，不启用；保留 46 死亡作为历史制度差异。
- 约束：LLR 额度/利率/期限；不能无条件兜底，避免道德风险。
- 会计：贷款创造存款（MMT）或准备金转移（Keynesian），显式记录
  `llr_loans`/`central_bank_money`。

### C. 食品券/紧急食品分配（Keynesian/MMT，古典可选慈善）

- 对 `cash < 最低口粮成本` 的家庭，政府发放食品券/直接转移，
  金额=0.1 吨食品×当月参考价（可覆盖儿童）。
- 资金：政府税收/债券/央行；金本位货币守恒。
- 也可让粮食储备按“零现金家庭”定向释放，而不是只按价格释放。
- 效果：即使工资链条断裂，家庭仍能买到最低口粮。

### D. 银行冻结规则校准（测试/政策）

- 50% 硬冻结是压力测试，不是现实政策；现实用资本/流动性比率、
  贴现窗口、部分准备金。
- 压力测试保留硬冻结；政策响应启用 LLR/食品券。
- 记录 `bank_frozen_cash`、`llr_loans`、`food_stamp_spending`。

## 3. 会计

- 工资欠款是负债，不是货币；支付时现金转移。
- LLR 贷款：Keynesian 准备金/债券转移；MMT 贷款创造存款；
  必须进入银行资产负债表/央行货币统计。
- 食品券：政府现金→家庭；家庭→企业；货币守恒；食品库存减少。
- 古典慈善：资本家/银行自愿出资；不能凭空造钱。
- 不得把未付工资直接注销；不得让食品券重复计入消费/转移。

## 4. 测试

- 单测：欠薪记录/下月优先支付；LLR 额度/利率；食品券只给零现金家庭；
  金本位货币守恒；MMT 央行货币显式增加。
- 冲击：复现 T120 信贷冲击 240 月；对比：
  - 死亡数（目标 Keynesian 165→<20，MMT 76→<10，古典保持或慈善改善）；
  - 零现金工人数、饥饿峰值；
  - 食品市场未成交、食品价格；
  - 政府债务/央行货币、银行坏账。
- 不得让无冲击基线出现 LLR/食品券支出（默认关闭/触发式）。
- 与人口/养老金模块兼容：食品券覆盖儿童/退休者；养老金收入计入家庭现金。

## 5. 参数草案

| 参数 | 建议 |
|---|---:|
| LLR 利率 | 政策利率 + 100–200bp |
| LLR 额度 | 单企业 2 个月工资 / 银行权益约束 |
| 食品券 | 0.1 吨食品等价/人/月，儿童 0.05 |
| 触发 | cash < 1 个月口粮成本 |
| 欠款优先级 | 工资 > 利息 > 本金 |
| 古典慈善 | 可选，资本家现金 0.1%/月 |

## 6. 与 D1 人口模块的交互

- 食品券/最低口粮要覆盖儿童/退休者；养老金收入计入家庭现金。
- 退休者没有工资欠款；LLR 只针对在业工资账单。
- 人口老龄化会提高食品券/养老金支出；需要财政恒等式。
