# 负利润率诊断与修复（V0.4.2）

> 现象：V0.4.1 三制度 240 月利润率约 -0.27% / -0.44% / -0.44%，
> 同时煤/铁/钢库存异常高。本文记录根因、修复和结果。

## 1. 根因一：计划分母与生产熟练度不一致（主因）

`_update_expectations_and_plans` 原来用 **skill=1 的产能** 做计划分母：

```
plan = desired_output / capacity_at_skill_one
```

但 `produce()` 又乘平均熟练度：

```
output = capacity × plan × utilisation × skill
```

熟练度到 2.0 后，实际产出是目标需求的约 **2 倍**。结果是：

- 煤 21,376 吨库存 ≈ 184 个月需求；
- 铁矿石 7,869 吨 ≈ 2,600 个月需求；
- 钢铁 2,793 吨 ≈ 890 个月需求；
- 机械 1,283 台 ≈ 500+ 个月需求。

工资、折旧、利息照付，但产出卖不出去，收入无法覆盖成本 → 负利润。
这不是“资本主义利润率下降”，而是单位错配造成的过度生产。

### 修复

```
effective_capacity = capacity_at_skill_one × max(1, average_skill)
plan = desired_output / effective_capacity
```

同时把“必需品固定 0.1 最低运行率”改为需求感知：

- 库存 >12 个月需求：只保留 2% 产能的涓流（避免整月零产出）；
- 否则最低运行率 = `min(0.1, 0.9 × 当前需求/有效产能)`。

## 2. 根因二：服务自雇的工资与经营所得重复

服务自雇企业 `is_household=True`，但 `_labor_market` 仍给它发工资；
`_finance` 又把经营现金扣除周转金后作为 payout 转给摊主，并从
`last_profit` 中减掉。结果是同一笔劳动收入被记了两次成本：

- 古典服务自雇：revenue 5,046，wage 6,084，profit -5,464/月。

### 修复

- `_labor_market` 跳过服务自雇：摊主不是雇员，`wage=0`；
- payout 仍作为家庭收入，但不再把自雇部门的负利润混入资本主义利润率。

## 3. 根因三：利润率把 household/自雇混进来

家庭农场所有者给自己发工资，服务自雇拿 payout；这些是**家庭劳动收入**，
不是资本回报。把它们计入“全社会利润率”会系统性压低利润率。

### 修复

- `profit_rate` 只统计非 household 的资本主义企业：
  `资本主义利润 /（设备+土地+库存）`；
- 新增 `capitalist_profit`、`capitalist_capital_stock`、
  `household_profit`、`household_capital`、`all_profit_rate`；
- 家庭/自雇收入另报，不伪装成资本利润。

## 4. 修复后 240 月（seed=1）

| 制度 | 存活 | 死亡 | 失业率 | GDP | 投资 | 资本主义利润率 | 全部口径利润率 |
|---|---:|---:|---:|---:|---:|---:|---:|
| classical | 1092 | 8 | 10.9% | 30,074 | 7,148 | **+0.30%** | +0.10% |
| keynesian | 1100 | 0 | 0.0% | 33,058 | 2,143 | **-0.01%** | -0.11% |
| mmt | 1100 | 0 | 0.0% | 35,014 | 1,126 | **+0.01%** | -0.05% |

- 资本主义部门利润率从 -0.27%/-0.44%/-0.44% 变为 +0.30%/-0.01%/+0.01%；
- 投资从 420/0/240 变为 7,148/2,143/1,126；
- 65 个测试通过。

## 5. 仍未解决

- 铁/机械/砖库存仍有 30–500 个月需求；2% 涓流只能慢慢消化；
- 建筑零产出 19/11/8 个月（<10%，但仍是尾部）；
- 古典 240 月 8 例死亡（利润率修正后底层流动性变紧）；
- `all_profit_rate` 仍略负，主要是 household/自雇劳动收入与亏损的结构；
- 信贷冲击死亡链（见 `CREDIT_SHOCK_DIAGNOSIS.md`）仍需最后贷款人/食品券。

## 6. 结论

负利润率主要是**模型单位错配 + 自雇会计 + 利润率口径**问题，不是经济规律。
修复后资本主义部门利润率已转正/接近零。下一步应处理库存消化、建筑需求和
底层流动性，而不是继续调价格或“接受负利润”。
