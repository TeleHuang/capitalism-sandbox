# ADR 0001 — V0.2 范围：先做可测试的经济内核，而不是完整 PRD

- 状态：已接受（临时）
- 日期：2026-10-24
- 背景：V0.1.1 能跑 240 个月，但工业链在第 2 个月附近冻结，农业从未转型，
  也没有企业会计和可测量的利润率。
- 决定：V0.2 实现一个确定性、可测试的月度内核：
  - 9 个行业和显式设备目录；
  - 双边拍卖 + 参考价试探过程 + 成本价格带；
  - 劳动市场：真实发薪、工时和失业；
  - 企业现金与所有者现金分离、银行工资周转贷、分红；
  - 土地市场和会购买农机/化肥的资本主义农场。
- 后果：
  - LLM 智能体、合同、期货、网页界面、场景 0/2 推迟；
  - 模型是刻意收窄的纵向切片，长期校准尚未完成；
  - 后续每个功能都必须在同一个变更里更新 `03_架构设计文档.md` 和测试。
