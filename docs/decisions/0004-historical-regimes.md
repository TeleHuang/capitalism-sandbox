# ADR 0004 — 历史阶段与政府/MMT 模块

- 状态：已接受（首版实现，待校准）
- 日期：2026-10-24
- 关联：V0.3.2 修复包、`docs/WORKSTREAM_V0.4.md`、`src/ecosim/government.py`

## 背景

用户要求仿真器能覆盖历史上各个阶段的资本主义，包括凯恩斯主义之前的时代；
同时希望 Keynesian/MMT 的“政府作为最终借贷人”可以被验证。
因此政策制度不能硬编码成唯一路径，必须是剧本配置开关。

当前 V0.3.2 的默认设定是：封闭经济、金本位、货币总量守恒、无政府、无出口。
这套设定对应 pre-Keynesian 的自由放任剧本；Keynesian/MMT 需要额外模块。

## 决定

### 1. 政策制度是 ScenarioConfig 字段，不是新引擎

新增：

- `src/ecosim/government.py`：`PolicyRegime`、`MoneyRegime`、`Government`。
- `ScenarioConfig`（`src/ecosim/scenarios.py`）：政策/货币/税收/救济/公共投资/就业保障参数。
- CLI：`python -m ecosim --regime classical|keynesian|mmt`。

三种预设：

| 预设 | 政策 | 货币 | 主要机制 |
|---|---|---|---|
| `CLASSICAL_LAISSEZ_FAIRE` | classical | gold | 无政府、无税收/救济/公共投资；价格带；私人粮商 |
| `KEYNESIAN_WELFARE` | keynesian | gold | 工资/利润税、失业救济、公共投资、债券；货币守恒 |
| `MMT_SOVEREIGN` | mmt | credit | 央行购买国债/创造货币；政府最后雇主（就业保障） |

默认场景仍是 classical，保证 V0.3.2 的历史行为可复现。

### 2. 政府账户与预算恒等式

- `Government.cash`、`debt`、`bond_holders`、`central_bank_money`。
- 月度流量：`tax_revenue`、`transfers`、`spending`、`interest_paid`、`deficit`。
- 预算恒等式：`deficit = spending + transfers + interest_paid - tax_revenue`。
- 金本位/Keynesian：政府支出不足时向资本家和银行发行债券；
  税收/转移/债券/利息都是现金转移，货币总量守恒。
- MMT/信用货币：央行购买国债并创造货币，`central_bank_money` 增加；
  `money_total` 允许增长，货币守恒告警在该模式下关闭。
- 政府现金计入 `total_money`；粮商/粮食储备现金也计入。
- 银行中介：classical 关闭（无政府/无存款保险，储蓄漏出会造成衰退）；
  Keynesian/MMT 启用——资本家/工人把闲置现金存入银行，银行用于周转贷；
  存款/利息都是现金转移，金本位下货币守恒。存款中介让 Keynesian 失业率
  从 41.9% 降到 16.9%。

### 3. 就业保障（最后雇主）

- MMT 模式下，私人部门招聘结束后，政府把剩余失业者吸收到公共工程。
- 工资 `jg_wage`，上限 `jg_max_workers`；工人 `employer_id="GOV"`。
- 公共工程产出 `BUILDING`，进入 `Government.public_capital`/库存。
- 政府工资从国库支付；不足时按 MMT/债券规则融资。

### 4. 粮食平准库存

- `FoodReserve`：高价（>1.15×初始价）释放、低价（<0.85×初始价）收储。
- 古典剧本里是私人粮商；Keynesian/MMT 里是政府战略储备。
- 只参与食品市场，不参与财政/货币创造；买卖都是现金转移。
- 目的：给制度切换/劳动力再配置一个缓冲，避免食品价格短期飙升造成饥荒。

## 首版实测（seed=1，240 月，L5/粮食储备/银行中介校准后）

| 指标 | 古典 | Keynesian | MMT |
|---|---:|---:|---:|
| 存活 | 1098 | 1100 | 1100 |
| 累计死亡 | 2 | 0 | 0 |
| 期末失业率 | 43.2% | 16.9% | 0.0% |
| 期末就业保障人数 | 0 | 0 | 452 |
| 期末政府债务 | 0 | 746,244 | 4,188,688 |
| 央行货币 | 0 | 0 | 4,188,688 |
| 货币总量 | 5,937,000 | 5,947,000 | 10,125,688 |
| GDP | 12,563 | 17,467 | 15,257 |
| 期末投资 | 0 | 0 | 706 |
| 利润率 | -0.08% | -0.20% | -0.01% |
| 钢/砖/机械零产出月 | 0/0/0 | 0/0/0 | 0/0/0 |

说明：
- 古典剧本不启用存款中介；Keynesian/MMT 启用银行中介（存款 600–713 万），
  这是 Keynesian 失业率从 41.9% 降到 16.9% 的主要原因。
- MMT 的就业保障把失业率压到 0；代价是央行货币/政府债务扩大到 419 万。
- 古典失业率仍高（43.2%），反映 9 行业模型缺少服务业/非正规部门，
  属于待校准项，不是历史定论。

## 后果与限制

- 政府/MMT 是**首版**：央行与财政部合并记账，没有完整国债市场、准备金利息、
  存款保险、银行资本充足率；这些属于后续 L4b。
- 没有消费税/财富税/出口/进口；公共投资只买建筑和机械。
- 粮食储备是临时稳定器，不是完整农业贸易/库存模型。
- 投资/利润仍偏弱（利润>0 月数 7/18/20），需要 L2 价格 markup + L5 工资曲线。
- MMT 的货币增长应进一步用通胀/汇率/产能约束校准，避免“无成本印钱”的误解。
- 古典剧本仍保留价格带/工资下限等安全阀；这些在 L2/L5 会替换成软走廊/工资曲线。

## 下一步

1. L2：成本加成 + 软价格走廊 + LES 需求，替换临时价格/工资安全阀。
2. L5：工资曲线/Phillips + 精确雇佣/解雇 + 跳槽阈值修正。
3. 历史剧本扩展：晚期资本主义（高集中度/金融化）、出口/开放经济。
4. 校准：把政府支出/税收/就业保障参数做成可扫描集，报告失业/通胀/债务/产出。
5. Python 稳定后同步 `web/engine-preview.html` 并重新生成 golden。
