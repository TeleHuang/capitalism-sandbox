## R-001 生产模型：2^N 规模表 vs α 幂函数

**需求位置**：2.3.3「2的N次方规模选型系统」与同节后面的「自然资源产业」「初级加工业」「重工业」产能设定。需求自己已经标注 `TODO：规模系数设定和上面的指数产能设定冲突`。

**冲突**：

- 2^N 表：设备规模翻倍 → 产量翻倍，工人 +1；
- α 公式：`产量 = A × (L/L_req)^α × 熟练度`，工人增加带来亚线性产能；
- 两套公式不能同时作为“固定设定”，因为同一批工人/设备的产出不同。

**本版临时选择**：`config.EQUIPMENT` 使用**设备目录 + 逐级容量表**，而不是 α 公式。制造业主设备按 2^N 思路设置档位（如炼钢炉 20/40/80 吨），农业/矿业用“土地/矿井 + 设备 + 工人”的专门规则。α 参数不再参与主流程。

**选项**：

- **A（推荐）**：把 2^N 设备目录定为唯一生产模型；删除或归档 α 段落，只保留“自然资源受土地/矿藏约束”的说明。
- **B**：保留 α 公式作为唯一模型，删除 2^N 表；设备规模只影响 A 和 L_req。
- **C**：两套并存，但明确分工：制造业用 2^N，农业/矿业用 α；需求文档必须写清边界。

**需要人决定**：选 A/B/C，并把 2.3.3 改成单一模型。

## R-002 初始场景总量与 2^N 表不一致

**需求位置**：第 3 节场景 1 与 2.3.3 设备表。

**冲突举例**：

- 场景说“3 座 50 吨级炼钢炉、40 名工人、满熟练度月产 100 吨钢”；
- 2^N 表说 50 吨炉 = 50 吨/月、3 名工人；满熟练度翻倍后 3 座应远高于 100 吨；
- 场景说“20 名纺织工、2000 件/月”，但 2.3.3 的工业织机 500 件、5 人；20 人满熟练度会高于 2000 件；
- 场景说“100 名建筑工”，但住房需求只有约 220 平米/月，而 100 名建筑工在 α 公式下产能远超需求。

**本版临时选择**：不追求逐项精确复现场景数字，而是用设备目录和初始设备数量**校准到叙事总量**：

- 3 座 20 吨炉、40 名工人，满熟练度约 120 吨钢/月；
- 20 台手织机、20 名工人，满熟练度约 2000 件布/月；
- 5 支手工施工队、100 名工人，满熟练度约 500 平米/月；
- 600 名自耕农、每人 10 亩，满熟练度 120 吨粮/月。

**选项**：

- **A（推荐）**：把场景 1 的“精确数字”改成“目标区间 + 校准表”，允许实现时用设备目录反推初始设备数量。
- **B**：保留精确数字，反过来修改 2^N 表，让每个行业的 base capacity/workers 与场景匹配。
- **C**：把场景 1 拆成“叙事版”和“校准版”两个配置文件。

**需要人决定**：选 A/B/C；如果选 B，需要逐行业重写 2.3.3 的基准值。

## R-003 农业企业为什么会出现？（本版已补机制，需确认）

**需求位置**：2.2.1、2.3.2、第 3 节场景 1。

**问题**：需求描述了自耕农、农机、化肥和“农业劳动生产率上升”，但没有写：

- 谁有权建立农业企业？
- 土地如何从自耕农转到资本主义农场？
- 农场为什么要买农机/化肥，而不是继续用 1 个农民 + 10 亩地？
- 食品价格由谁决定，农业利润信号从哪里来？

这正是上一版模拟暴露的问题：**农业产出紧平衡、工业品在产出，但没人建立农业企业、投资农机和化肥，农业劳动生产率一直不动。**

**本版临时选择**（已实现）：

- 固定 6000 亩土地，600 个自耕农各 10 亩；
- 土地市场：自耕农在价格 ≥ 150 元/亩时卖地；资本主义农场按 回报率 ≥ 1.2%/月买地；
- 农业企业可以雇工、买农机（提高人均土地）、买化肥（亩产翻倍）；
- 食品价格由市场决定，食品短缺 → 农业 回报率 上升 → 买地/投资；
- 自耕农卖地后变成无地劳动者，可被农场或工业雇佣。

**选项**：

- **A（推荐，已实现）**：土地市场 + 资本主义农场 + 化肥/农机市场。
- **B**：国家/政府主导的农业投资公司（不依赖私人土地市场）。
- **C**：自耕农合作社 + 信用合作社（小农集体买农机/化肥）。
- **D**：A + C 并存，允许两条路径竞争。

**需要人决定**：是否把 A 写进需求文档 2.3.2/第 3 节；如果希望更接近某国历史，选 A/B/C/D 并补充土地制度。

## R-004 资产阶级消费与总需求

**需求位置**：2.2.3、2.4、2.5。

**问题**：需求说董事持有大量资金、决定注资/撤资，但没有写他们**消费什么、消费多少**。如果资本家只储蓄不消费，社会总需求只剩工人工资，经济会内生成“消费不足”，但这是由规则硬编码的，不是演化结果。

**本版临时选择**：资本家每月消费 `max(100, 现金×2%)`，购买食品/衣物/住房（目标 0.1 吨、5 件、1 平米）。这是临时校准，不是历史估计。

**选项**：

- **A（推荐）**：在需求中明确“资本家消费函数”：按财富比例消费，或按社会地位消费篮子；并说明是否包含奢侈品/服务。
- **B**：资本家只消费固定篮子，剩余全部投资；总需求由投资驱动。
- **C**：引入政府支出/公共工程，作为独立最终需求。
- **D**：开放出口部门，用外部需求吸收剩余。

**需要人决定**：选 A/B/C/D；如果选 A，给出消费率或篮子。

## R-005 价格形成：平均价 + 硬钳位是否足够？

**需求位置**：2.5「匹配与定价机制」。

**问题**：需求只写“最高买价与最低卖价匹配，成交价取平均”，没有写：

- 买价 < 卖价、但双方都有交易意愿时，价格如何调整？
- 价格是否允许跌破成本/高于成本数倍？
- 薄市场只有一两笔成交时，价格如何避免被单笔交易带飞？

V0.1 的教训：没有成交时价格完全不动，煤/铁/钢跌到成本以下后永远无法恢复；末期价格又被 5%~20× 初始价的硬钳位接管。

**本版临时选择**：

- 双边拍卖 + 参考价 试探过程（成交价 70/30 平滑 + 供需不平衡调整）；
- 报价围绕参考价，买卖价差很窄；
- 成本价格带作为安全轨：参考价限制在“单位成本中位数 × 0.9~2.5”并受初始价锚定。

**选项**：

- **A（推荐）**：保留“双边拍卖 + 参考价 + 成本带”，把成本带写成明确的 做市商 规则。
- **B**：纯双边拍卖，不设参考价；允许价格长期不成交。
- **C**：集中撮合/拍卖师定单一出清价，所有成交按同一价格。
- **D**：成本加成定价（cost-plus），价格由卖方成本决定。

**需要人决定**：选 A/B/C/D；如果选 B，需要接受市场冻结和长期短缺。

## R-006 劳动工时、失业与死亡

**需求位置**：2.2.1「每天可工作16小时」「生活标准」「长期生存区间随机死亡」。

**问题**：

- 需求没有写 8/12/16 小时如何选择、工资是否按工时比例；
- “长期处于生存区间有随机死亡概率”没有定义“长期”；
- 没有写失业者是否继续消费、是否有救济、是否可以用储蓄买地/创业。

**本版临时选择**：

- 工人按储蓄/缺粮选择 16/12/8 小时，工资按工时比例；
- 连续饥饿 ≥3 个月后每月死亡概率 8% 起，最高 50%；
- 失业者没有救济，只能花储蓄；自耕农卖地后可获得现金；
- 没有工会、最低工资法、失业保险。

**选项**：

- **A（推荐）**：在需求中定义“生存区间”的月数阈值和死亡概率曲线；
- **B**：死亡只由食品库存 = 0 触发，取消随机死亡；
- **C**：加入失业救济/慈善/家庭互助，降低死亡但不取消；
- **D**：加入工会/最低工资，改变工资议价。

**需要人决定**：选 A/B/C/D，并给出“长期”的月数。

## R-007 企业会计、资产估值与利润率

**需求位置**：2.4（明确批评“董事现金比资产还多”）、2.6.3（资产负债表）。

**问题**：需求要求展示企业资产/负债，但没有定义：

- 固定资产如何估值（历史成本/重置成本/市场价）？
- 土地是否计入企业资产？
- 利润率分母是总资产、固定资本、还是权益？
- 亏损企业如何破产，资产如何处置？

**本版临时选择**：

- 企业现金与所有者现金分离；
- 设备按资本品当前价格重置估值；土地按地价估值；库存按市价；
- 利润 = 收入 − 中间投入 − 工资 − 利息 − 折旧；
- 利润率 = 利润 /（土地 + 设备 + 库存）；
- 破产条件包含净资产 < 0；资产处置仍是简化版。

**选项**：

- **A（推荐）**：在需求中明确“利润率 = 利润 / 固定资本 + 流动资本”，并定义估值口径。
- **B**：用历史成本 + 折旧，避免市场价格波动导致账面利润剧烈变化。
- **C**：同时报告“账面利润率”和“市场价值利润率”。

**需要人决定**：选 A/B/C；这是“验证利润率下降”的核心口径。

## R-008 化肥产业链缺失

**需求位置**：2.3.2 化肥厂、2.3.3 化肥产能。

**问题**：需求把化肥列为一级产品，但旧代码 `FERTILIZER_FACTORY.output = None`，`Goods` 里没有化肥，导致化肥产业链不存在，农业无法通过化肥提高亩产。

**本版处理**：已补 `Good.FERTILIZER`、化肥厂产出、化肥投入（每亩 0.01 吨/月，亩产翻倍）、化肥行业进入。需求文本不需要大改，但建议补一句“化肥是农业的可选投入，未使用时产量为基础值”。

**选项**：

- **A（推荐）**：保留“化肥翻倍、每亩 0.01 吨/月”的设定，写进需求。
- **B**：改成边际报酬递减（例如 +50% 而不是翻倍），更接近农学。
- **C**：化肥需要农机配合（只有机械化农场才能用化肥），形成技术互补。

**需要人决定**：选 A/B/C。

## R-010 交付形态：Python 参考实现 vs HTML 最终发行版

**需求位置**：新增第 5 节「交付形态与语言要求」。

**需求内容**：

- 所有文档、代码注释、运行说明使用中文；
- Python 版用于逻辑验证，不是最终发行版；
- 最终发行版必须是可以直接在浏览器运行的 HTML。

**尚未写明的部分**：HTML 版的实现方式。

**选项**：

- **A（推荐）**：JavaScript/TypeScript 重写引擎 + 静态 HTML。优点：离线、启动快、部署简单；缺点：两套实现，需要黄金运行样例交叉验证。
- **B**：Pyodide 在浏览器里运行 Python。优点：逻辑唯一；缺点：首次加载体积大、速度慢。
- **C**：Python 后端 + HTML 前端。优点：逻辑唯一；缺点：需要服务器，不是纯静态 HTML 发行版。
- **D**：Python 离线生成 HTML 快照。优点：简单；缺点：只能看回放，不能交互。

**本版临时选择**：`web/` 目录先留规划，尚未实现 HTML 引擎；Python 继续作为唯一权威逻辑。详细论证见 [[docs/decisions/0003-html-release.md]]。

**需要人决定**：选 A/B/C/D；以及 HTML 发行版是否必须完全离线。
