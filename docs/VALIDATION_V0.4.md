## 0. 结论摘要

1. **负反馈在方向上生效，但路径收敛很慢。** 三种制度在需求、生产率、信贷冲击后都没有
   出现永久性核心行业零产出或全灭；首次回到基线 ±10% 通常在 11–33 个月
   （GDP/物量产出口径），但要求“从此不再偏离”的严格路径收敛往往要到 T240
   附近（89–120 个月）。后者主要反映模型的内生库存—投资周期，而不是 90 个月的
   深度萧条。
2. **需求冲击下 Keynesian 的产出损失最大，MMT 的失业率仍最低。** T120–T131 的
   GDP 净变化：classical −5.0%、Keynesian −22.9%、MMT −12.5%。MMT 的失业率峰值
   仍接近 0（就业保障吸收），代价是政府债务/央行货币在部分冲击后上升。
3. **生产率冲击首先表现为物量下降，名义 GDP 可能反而上升。** 农业/工业产出乘数
   下降 10–15% 时，classical 物量产出冲击窗 −10.2%、Keynesian −12.8%、MMT −7.7%；
   但价格上升使名义 GDP 在 classical/Keynesian 反而为正。MMT 的食品价格峰值涨幅
   达到 +64.1%，值得作为粮食安全风险单独跟踪。
4. **信贷渠道在当前模型里不是紧约束。** classical 的信贷冲击完全没有效果；
   Keynesian/MMT 的冲击窗 GDP 净变化接近 0。唯一清晰的效果是 MMT 的财政成本：
   利率 +300bp 持续 12 个月后，政府债务/央行货币比基线高约 117 万。
5. **单路径峰值不可当作精确冲击乘数。** 模型有强内生周期：仅 1% 需求扰动或
   1bp 信贷扰动，就能让 3 月移动平均 GDP 峰值偏离 0–31%。因此本报告以冲击窗
   累计净变化、失业/零产出/债务方向为主，峰值只作辅助。
6. **会计与守恒不变量通过。** 43 个测试（33 个原有 + 10 个新增不变量/冲击钩子测试）
   全部通过；金本位货币守恒、`bank.loans == Σ enterprise.debt`、政府预算恒等式、
   无负库存、土地总量恒定、统计字段无 NaN/Inf、三制度 60 月存活均成立。

## 1. 方法与范围

### 1.1 场景与运行

- 场景：`build_scenario_1`，即第一次工业革命/农业国工业化场景。
- 制度：`classical`（自由放任、金本位、无政府）、`keynesian`（税收/UI/公共投资、
  金本位、银行中介）、`mmt`（主权信用货币、央行、就业保障）。
- 月数：240 个月。
- 种子：1、2、3。
- 冲击起点：T120；持续 12 个月（T120–T131）；之后继续跑到 T240。
- 对照：同一制度、同一 seed 的无冲击路径。所有冲击路径与基线路径在 T119 之前
  完全相同，因此 T120 之后的差异由冲击（及其非线性后果）引起。

### 1.2 冲击定义

冲击通过 `Engine` 上的中性钩子实现；默认值全部为“无冲击”，不改变三制度基线行为：

| 冲击 | 操作 | 默认/恢复值 |
|---|---|---|
| 需求 | 家庭非食品消费 ×0.80；资本家消费预算 ×0.70；Keynesian/MMT 的 `public_investment_rate` 与逆周期项临时归零 | `worker_demand_scale=1.0`、`capitalist_demand_scale=1.0`、原政府参数 |
| 生产率 | 农业产出乘数 ×0.90；非农行业 ×0.85；投入品随产出同比例下降 | `Engine.productivity_multipliers={}` |
| 信贷 | 银行利率 +300bp；工资缺口贷款只发放 25%；冻结 50% 银行现金为不可放贷准备金（仍计入货币总量） | 原利率、`lending_scale=1.0`、解冻准备金 |

说明：

- 食品购买不削减。需求冲击只削减衣着/住房等非食品消费，避免把需求冲击变成饥荒
  冲击；食品价格仍会通过收入与生产链间接变化。
- classical 没有政府，因此其“需求冲击”只包含私人消费；Keynesian/MMT 还包含公共
  投资削减。跨制度比较时需记住这一构成差异。
- 信贷冲击的“冻结准备金”是资产负债表内的科目重分类（`bank.cash -> bank.frozen_cash`），
  不是货币销毁；冲击结束后解冻。这样既降低可贷资金，又保持金本位货币守恒。
- 生产率乘数只作用于 `produce()` 的实际产出，不改变企业的产能/投资判断；这是刻意
  的最小实现，避免冲击永久改写资本存量决策。

### 1.3 指标

| 指标 | 定义 |
|---|---|
| GDP | `consumption + investment + government_spending`（月度市场交易额） |
| 物量产出指数 | 各行业月产量 × 初始价格之和（固定价格，避免价格效应） |
| 冲击窗净变化 | `(Σ冲击路径 − Σ基线路径) / Σ基线路径`，窗口 T120–T131 |
| 24 月净变化 | 同上，窗口 T120–T143 |
| 全期净变化 | 同上，窗口 T120–T240 |
| 峰值(MA3) | 3 月移动平均路径相对基线的最大不利偏离 |
| 半衰期 | 从 MA3 谷底恢复到峰值缺口一半所需月数 |
| 首次恢复 | 冲击结束后首次连续 3 个月回到基线 ±10% 的月数（可能再次偏离） |
| 持续恢复 | 从某月起直到 T240 都不再偏离基线 ±10% 的月数；“—”表示窗口内未实现 |
| 累计低于基线 | T120–T240 中低于基线的月度差额之和 / 基线累计值 |
| 零产出 | 钢/砖/纺织/机械/建筑中任一行业月产量为 0 的月数；食品单独统计 |
| 政府债务/央行货币 | 期末水平与同 seed 基线的差 |

恢复指标使用 3 月移动平均，原因是月度 GDP 有很强的库存—投资周期；单月峰值会把
周期相位差误读成冲击幅度（见第 5 节安慰剂带）。

### 3.2 需求冲击

- **classical：−5.0% 冲击窗、−2.8% 24 月、−0.4% 全期。** 物量产出冲击窗 −4.0%。
  失业率在冲击窗内的基线峰值 46.5%、冲击峰值 45.9%，没有进一步抬高中枢；核心
  行业零产出 0 个月。古典经济本来就处于高失业/供给约束状态，削减需求更多改变
  消费构成与周期相位，而不是造成持续产出损失。
- **keynesian：−22.9% 冲击窗、−10.1% 24 月、−2.0% 全期。** 物量产出冲击窗
  −12.8%、全期 −5.3%，是三种制度中损失最大的。失业率基线峰值 39.6% → 冲击
  峰值 42.5%。公共投资削减与私人消费削减叠加，乘数效应明显。政府债务期末比
  基线低 41,690（经济收缩导致公共投资/税收流量下降），不是财政扩张。
- **MMT：−12.5% 冲击窗、−6.3% 24 月、−1.2% 全期。** 物量产出冲击窗 −10.1%、
  全期 −0.8%。就业保障把失业率压在 0.5% 附近（单月 JG 吸收滞后），代价是政府
  债务/央行货币比基线高 48,742。部分 seed 出现 1 例额外死亡，说明需求收缩通过
  收入—食品购买链条仍可能造成生存后果。

### 3.3 生产率冲击

- **classical：名义 GDP 冲击窗 +12.4%，但物量产出 −10.2%。** 农业产出乘数 0.90、
  工业 0.85，食品产出峰值下降 11.0%、食品价格峰值上涨 11.6%。名义 GDP 上升是
  价格效应，不能解读为繁荣。全期物量产出 −0.5%，基本恢复。
- **keynesian：名义 GDP +11.3%，物量产出冲击窗 −12.8%、全期 −5.2%。** 冲击期
  出现 3 个核心行业零产出月（信贷冲击另有 2 个），说明产业链在供给冲击下会出现
  短期停摆；食品价格峰值 +11.1%。
- **MMT：名义 GDP +30.6%，物量产出 −7.7%。** 食品产出峰值 −15.5%，食品价格
  峰值 +64.1%，是本次测试中最大的价格冲击。就业保障把失业率压在 1.8% 以下，
  但粮食安全风险需要通过储备/进口/价格政策单独处理。

### 3.4 信贷冲击

- **classical：完全无效果。** 古典制度没有银行中介，企业工资缺口贷款规模很小，
  利率 +300bp 对仅约 1.4 万的存量债务几乎没有宏观影响。这是模型结构，不是
  “信贷冲击不重要”的现实结论。
- **keynesian：接近零。** GDP 冲击窗 +0.3%、24 月 −0.0%、全期 +0.9%；物量产出
  +1.0%/+1.5%。失业率峰值不变（39.6%），但冲击期出现 2 个核心零产出月，说明
  路径分叉/局部停摆仍存在。政府债务期末比基线高 134,054（利率上升的利息成本）。
- **MMT：实际产出接近零，财政成本显著。** GDP/产出冲击窗约 0，24 月 GDP −1.0%；
  政府债务/央行货币期末比基线高 1,172,131。机制是利率 +300bp 持续 12 个月，
  政府债务利息被央行/银行持有并资本化，MMT 下通过新增货币/债务融资。就业保障
  的失业率峰值为 5.5%，但基线自身也有 4.4% 的单月 JG 吸收滞后峰值。

**结论：在当前模型中，信贷不是第一约束。** 这与此前 `docs/WORKSTREAM_V0.4.md`
的诊断一致：企业主要靠自有现金/所有者注资周转，银行工资缺口贷款规模很小；
真正的约束是需求、产业链和劳动配置。

### 3.5 恢复、零产出与死亡

- **首次恢复**（连续 3 个月回到 ±10%）：需求冲击 11–15 个月，生产率冲击 11–12 个月，
  信贷冲击 11 个月（或 0，如果峰值本身小于 10%）。
- **持续恢复**（直到 T240 不再偏离）：需求 90–118 个月，生产率 89–120 个月，
  信贷为 0（峰值本身低于阈值）、107 个月或未实现。这个口径对混沌路径非常严格；
  不应把它读成“90 个月衰退”。
- **核心零产出**：classical/MMT 在所有冲击期均为 0；Keynesian 生产率冲击 3 个月、
  信贷冲击 2 个月。食品零产出在所有冲击中均为 0。
- **死亡**：classical 各冲击与基线相同（均值 1.7，来自 seed 差异）；Keynesian 均为 0；
  MMT 需求冲击均值 1.3，其余为 0。没有出现冲击导致的全灭或大规模饥荒。

## 4. 不变量与测试

`tests/test_invariants.py` 在 60 个月、三制度上逐月检查：

- 金本位货币守恒：classical/keynesian 的 `money_total` 与 `money_initial` 偏差 < 0.01；
- `bank.loans == Σ enterprise.debt`（含资本化未付利息）；
- 政府预算恒等式：`deficit = spending + transfers + interest − tax`；
- 企业/项目/政府/资产池/家庭库存非负；
- 土地总量恒定：自耕农土地 + 资本主义农场土地 + `estate_land` + `asset_pool.land`
  = 6,000 亩（家庭农场企业上的土地是自耕农土地的会计镜像，不重复计入）；
- 统计字段无 NaN/Inf；
- 三制度 60 月 `alive > 1,000`；
- 新增冲击钩子默认中性（乘数 1.0/空字典、`frozen_cash=0`）；
- 未付利息会计入 `bank.loans`；冻结准备金不改变货币总量。

### 4.1 会计修正

本轮修正了一个明确的会计 bug：`Bank.charge_interest` 过去只把未付利息加到
`enterprise.debt`，没有加到 `bank.loans`。结果是 `bank.loans` 系统性小于
`Σ enterprise.debt`，破产核销 `bank.write_offs` 也会漏记这部分。现在未付利息
同时资本化到 `bank.loans`；这不改变任何企业/家庭决策或宏观路径，只修正银行资产
与核销统计。`bank.frozen_cash` 同理只是资产负债表科目，计入货币总量。

## 5. 混沌 / 安慰剂带（重要）

模型除饥饿死亡外是确定性的，但**不是稳定的**：它存在强内生库存—投资周期，
微小扰动即可让路径在数月后大幅分叉。为量化这一点，脚本默认额外运行两个安慰剂：

| 制度 | 安慰剂：1% 需求扰动 GDP峰值(MA3) | 1bp 信贷扰动 GDP峰值(MA3) |
|---|---:|---:|
| classical | 30.9% | 0.0% |
| keynesian | 29.5% | 24.7% |
| MMT | 12.0% | 8.1% |

安慰剂扰动的冲击窗净变化几乎都是 0（−0.2% 到 +0.4%），但峰值可以达到主冲击峰值的
同一量级。因此：

- **不要用单路径峰值/半衰期/持续恢复月数当精确冲击乘数。**
- **优先看冲击窗/24 月累计净变化、方向性指标（失业、零产出、债务/货币）。**
- 若要估计分布，应做 20–100 个 seed 的蒙特卡洛，或对冲击起点（T108–T132）做集成；
  当前 3 个 seed 只能覆盖饥饿死亡抽签，不能覆盖路径不确定性。
- 这也解释了为什么 classical 的信贷冲击恰好为 0：没有银行中介时，利率冲击
  不改变任何实际决策；这不是“模型稳定”的证据。

## 6. 局限

1. **确定性 + 饥饿死亡。** 同一 seed 完全确定；不同 seed 只在有人饿死时不同。
   Keynesian/MMT 无死亡，所以 seed 结果逐位相同。3 个 seed 不等于统计分布。
2. **强内生周期/混沌。** 见第 5 节；单路径冲击指标噪声很大。
3. **只有 9 个行业，没有服务业/非正规部门。** 失业率结构性偏高（classical 43%），
   劳动吸收与冲击传导缺少服务业缓冲。
4. **L2 未完成。** 默认仍是固定温饱篮子 + 价格带；`markup`/`les` 是实验分支。
   价格/工资仍有临时安全阀（价格带、工资 5× 上限、粮食储备）。
5. **银行/政府资产负债表简化。** MMT 的央行与财政部合并记账，没有完整国债期限
   结构、银行资本、准备金制度；政府债券只区分银行/资本家/央行。
6. **信贷渠道弱。** 企业工资缺口贷款规模很小，且没有抵押品、风险溢价、企业债券、
   银行挤兑/破产传染。信贷冲击结果主要说明“当前模型里信贷不紧”，不能外推。
7. **冲击实现是最小钩子。** 生产率乘数只作用于实际产出；需求冲击不削减食品；
   classical 的需求冲击没有政府部分；信贷冲击是临时准备金冻结，不是银行危机；
   企业/家庭没有预期和前瞻行为。
8. **名义 vs 物量。** 生产率冲击下名义 GDP 可能上升；报告同时给出物量产出指数，
   解读时以物量为主。
9. **恢复口径。** 首次恢复可能只是暂时穿回基线；持续恢复在混沌系统里非常严格。
   两者都报告，避免把“路径碰巧穿回”当成结构性恢复。
10. **未覆盖。** 出口/进口、外汇、完整农业贸易、设备 vintage/age、Calvo 定价、
    LLM 经理行为、20–100 seeds 统计检验。

## 8. 建议的下一步

1. **用 20–100 seeds 或冲击起点集成替代单路径峰值**，报告分布的中位数/90% 区间，
   而不是一个 seed 的点估计。
2. **把冲击窗净变化作为主验收指标**；峰值/半衰期只作辅助，并同时给出安慰剂带。
3. **补服务业/非正规部门**，降低 classical 的结构性失业，并给需求冲击提供劳动
   吸收缓冲。
4. **完成 L2（markup + LES）**，用需求弹性替代固定篮子，再重跑本套冲击测试。
5. **信贷渠道**需要企业债/抵押品/风险溢价/银行资本，否则信贷冲击只能验证会计
   守恒，不能验证金融加速器。
6. **粮食安全**：MMT 生产率冲击的食品价格 +64% 说明需要把储备/进口/价格上限
   作为独立政策模块，而不是只靠临时价格带。
