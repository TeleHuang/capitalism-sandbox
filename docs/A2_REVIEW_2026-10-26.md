## 如何解读宏观变化

修复前的高 GDP/低失业有一部分来自**被掩盖的缺陷**：

1. 钢厂因规划缺陷放弃铁矿，钢铁/机械长期短缺；旧统计里的“高价格”
   是短缺租金，不是健康的产出。
2. 替换项目超时丢失、僵尸企业占位、死亡耐用品泄漏，都会人为维持
   某些需求或行业名额。
3. 修复后供给链恢复（keynesian/MMT/late 的机械从 0 恢复到 8–18），
   但 classical free 暴露出**名义需求不足**：钢铁/机械价格下行、
   投资与就业收缩。旧 20.7% 失业并非健康均衡，而是短缺/积压项目
   撑起来的表象。

因此本次修复不把古典失业调回旧值（那会重新引入供给/会计缺陷），
而是把需求/货币缺口明确留给 **C：银行贷款创造存款、准备金/资本约束、
央行通胀/利率反应函数**。A2 的存量/废钢/土地机制保持默认开启；
A2-off 仍是 Python oracle 的同口径回放。
