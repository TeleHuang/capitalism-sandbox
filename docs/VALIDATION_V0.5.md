# V0.5 长程验证（seed=1）

> 工具：`scripts/validate_v05.py`；输出 `artifacts/validation_v05/seed1_{240,1200}.json`。
> 检查项：人口不灭绝、最后 12 个月仍有出生、累计饥饿死亡、金本位货币守恒、
> 养老金基金/预算恒等式、统计字段有限。

## 命令

```powershell
$env:PYTHONPATH = "src"
python scripts/validate_v05.py --months 240  --seed 1 --jobs 4
python scripts/validate_v05.py --months 1200 --seed 1 --jobs 4
```
